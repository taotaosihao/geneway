# geneway 责任说明

本轮按用户要求使用 Atlas native Team 做只读合同审查，不做代码实施或人员编制承诺。

- 合同可执行性审查：检查 Atlas lint、First-code、阶段依赖、验收归属和 GearJob 前置。
- 架构安全审查：检查身份授权、Model Gateway、事件账本、Hatchet fencing、审批和对象存储。
- 产品/UI 审查：检查小纬单一身份、异常待办、Workflow、响应式、表格和错误状态。
- 集成与最终裁决：当前主 Agent；仅把主审验证并接纳的问题写回权威合同。

- 文档与合同维护：当前主 Agent。
- 范围、Capability 业务合同、真实数据和毕业决定：人类产品/制造业负责人。
- 下一轮代码实施：由用户授权的主实现负责人承担；可按 Platform、Runtime、Connector、Web/Channel、Evidence/Eval、安全运维拆分逻辑责任。
- 共享订阅开发车道：必须指定一个人类凭据负责人，独占 refresh/login 操作并核对配额、auth-file 权限和停用；Agent 不读取或修补 token。
- 安全、数据出域、真实系统接入和 D1+ 扩权：必须由对应人类责任人独立批准。

同一人可以兼任工程角色，但不得用 Agent 自批或同一自动化主体代替要求职责分离的业务/安全审批。
